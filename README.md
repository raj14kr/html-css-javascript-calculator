 Calculator Projects Collection

A collection of calculator projects built using HTML, CSS, and JavaScript. This repository includes different calculator designs, utility tools, and converters with unique UI styles and functionalities.

🛠️ Technologies Used

HTML5 — Application structure

CSS3 — Styling, layouts, and responsive design

JavaScript — Calculations and interactive functionality

✨ Features

Multiple calculator applications in one repository

Different modern UI designs and themes

Interactive calculations and conversions

Beginner-friendly front-end projects

Practice with JavaScript logic and DOM manipulation

🚀 How to Run

Clone the repository:

https://github.com/raj14kr/html-css-javascript-calculator

Open the cloned project folder.

Select the calculator project you want to run.

Open its index.html file in your web browser.

You can also open the project in Visual Studio Code and use the Live Server extension.

🎯 Purpose

This repository demonstrates front-end development skills, JavaScript problem-solving, UI design, and the implementation of practical calculator applications.
